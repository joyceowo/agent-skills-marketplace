# Portal 公告

此分支僅用於使用者要求建立的 B2C 上線公告。沿用已確認的目標 Portal、公告受眾與可用工作階段。優先使用有相應能力的 B2C 工具。需要 UI 時先用內部瀏覽器，能沿用已登入分頁就沿用。確認內部瀏覽器無法使用後，才詢問是否改用 Chrome。若目前工具無法上傳本機 PDF，先交付 HTML 並回報待處理的上傳步驟。缺少目標環境或必填欄位時，依目前可見欄位確認資訊。

1. 讀取本次 HTML 的 `meta[name="portal-announcement-title"]` 的 `content`，取得格式為 `[上線通知] - 系統與功能` 的公告標題。開啟「公告系統」，以此標題查詢是否已有同案，必要時用功能名稱搜尋舊格式。需要新建時點「新增」，將同一個公告標題填入 `Title`，再依本次通知填寫 `Description`，`Type` 選 `System`。
2. 從本次交付 HTML 的「產生 PDF」取得 `Document.pdf`，或從同一份 HTML 取出內嵌 PDF。若瀏覽器因同名檔加上編號，先核對內容並在工作目錄使用 `Document.pdf` 檔名。進入 `File Upload` 的「上傳檔案」，在附件面板選擇該 PDF。確認檔名為 `Document.pdf` 後按「確認 (Confirm)」，等面板關閉並確認表單顯示一個附件。
3. 供本人驗證時，確認 `View Role` 與 `Edit Role` 都是「僅限本人」，再依建立授權按「儲存」。若本次只獲准準備預覽，或儲存會將公告開放給其他人，先提供實際表單內容和可見範圍供確認。
4. 儲存後從列表找到該公告並開啟「檢視」。核對 `Application No.`、標題、`Type = System` 和權限。開啟 `Files` 的「下載檔案」，確認已儲存的附件清單列出 `Document.pdf`。提供公告編號、檢視連結及附件核對結果。若結果不明，先按標題查詢，避免重複儲存或建立。
5. 確認公告已建立後，在結果中列出「待完成項目」，提醒使用者「請手動到公告系統測試這則公告，測試完成後，將 `View Role` 改成『所有人』並儲存。」只有使用者另行要求代為調整時，才確認受眾並依授權調整，再重開檢視頁核對實際範圍。
